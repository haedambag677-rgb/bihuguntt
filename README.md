# 폰 부수기 실험실

브라우저에서 바로 하는 3D 폰 부수기 게임이에요. 설치 없이 링크만 열면 돼요.

## 이런 걸 할 수 있어요
- 갤럭시 · 아이폰 · 피처폰 · MP3 · 태블릿 · 노트북 등 수백 종의 기기 (B: 기종 선택)
- 망치(H) · 옥상 낙하 · 수조 방수 테스트 · 세탁기(드럼 · 통돌이) · 파괴 실험 단지 57곳
- 폰 OS: 잠금 해제 · 카메라(슬로모션 등 여러 모드) · AI 비서(T)
- 플레이스테이션: PSP-1000/2000/3000 · PS3 · PS4 Pro · 듀얼쇼크 3/4, 게임 디스크(F)

## 기본 조작
| 키 | 기능 |
|---|---|
| W A S D / 마우스 | 이동 · 시점 |
| B | 기종 선택 |
| F | 줍기 (PS 기기 근처에서는 게임 디스크) |
| G | 내려놓기 (짧게: 뒷면 보기) |
| P | 전원 |
| Q | 화면 확대 |
| H | 망치 |
| C | 충전 · PS3/PS4를 TV에 HDMI 연결 |
| 1~9 · M · U · N · L | 장소 이동 |

※ 게임 속 로고와 상표는 모두 실제와 다른 근사치예요. 실제 회사와 관련이 없는 팬 게임이에요.
